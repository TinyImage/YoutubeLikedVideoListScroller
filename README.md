# YouTube Liked Videos Auto-Scroller (robust)

This Tampermonkey userscript automatically scrolls through the YouTube **"Liked Videos" (LL) playlist** and loads all video entries.

## Features
- Auto-scrolls until all videos are loaded
- Simple badge + start/stop button
- Keyboard shortcuts:
  - **Shift + A** → Start autoscroll
  - **Shift + X** → Stop autoscroll
- Safety limits and smart waits for YouTube spinners

## Installation
1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Install the script.
3. Open your YouTube [Liked Videos playlist](https://www.youtube.com/playlist?list=LL).
4. Use the button or shortcuts to start autoscrolling.

---

**Note:** This script is for personal use only. YouTube may change its layout at any time, which could break the script.
